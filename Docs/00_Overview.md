# 00. 개요

## 컨셉

- **확실한 노가다** 채굴 게임
- **B급 병맛**: 이상한 광물을, 확실하게 이상한 그림체로, 정말 이상하게
- 플랫폼: PC (키보드 + 마우스)
- 목표 진행: 약 15일 동안 곡괭이 Lv1 → Lv6, 1층 → 5층 (→ `08_Balance.md`)

## 핵심 루프

```
기상 → 광산 진입 → 채굴 (랜턴 소모) → 지상 귀환 → 까마귀가 광물 회수
  ↑                                                    ↓
뉴스(시세 확인) ← 인터넷 쇼핑 ← 핸드폰 정산 ← 귀가 & 취침(자동저장)
```

## 하루 흐름

1. **기상**: 전날 밤 인터넷 쇼핑으로 주문한 물품이 풍선을 타고 도착해 있다.
2. **채굴**: 광산(맵 영역)에 들어가면 랜턴 배터리가 줄기 시작한다.
3. **귀환**: 배터리가 다 떨어지기 전에 지상(맵 상단 4칸 이내)으로 올라와야 한다.
   - 실패 시 암전 → 그날 모은 광물 50% 손실 → 구조대 구출 → 구출 비용 지불 (→ `04_Lantern_Day.md`)
4. **판매**: 광산에서 나오면 바로 까마귀가 광물을 가져간다.
5. **귀가 & 취침**: 집에서 랜턴을 충전하며 잠든다. 이때 자동저장.
6. **핸드폰**: 취침 상호작용 시 오늘 판매한 광물 값 정산 → 인터넷 쇼핑
7. **잠자기(암전) → 뉴스**: 다음 날 시세 변동 확인 후 기상

순서 요약: `정산 → 상점 → 잠자기(암전) → 뉴스 → 기상`
