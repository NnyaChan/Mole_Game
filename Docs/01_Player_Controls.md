# 01. 플레이어 & 조작

## 플레이어

- 크기: 블록 1칸
- 이동 속도: 3 (유닛/초, `PlayerManager.speed`)

## 조작

| 입력 | 동작 | 구현 |
| --- | --- | --- |
| A / D | 좌우 이동 | ✅ `PlayerManager.Move` |
| W / S | 벽타기 중 상하 이동 | ✅ |
| Shift | 벽타기 모드 진입 | ✅ `PlayerManager.ClimbCheck` |
| 마우스 위치 | 곡괭이 방향(조준) | ✅ `TileBreaker` |
| 마우스 좌클릭 (누르고 있기) | 채굴 | ✅ `MiningController` |
| 인벤토리 아이템 클릭 | 아이템 사용 | ❌ 미구현 |

## 곡괭이 조준

- 원 기획: 마우스 포인터 방향에 따라 곡괭이가 움직인다 (참고: 세피리아). 곡괭이와 겹치는(가장 가까운, 1칸 이내) 블록이 파괴된다.
- 현재 구현:
  - 플레이어 → 마우스 방향 각도를 **8방향**(위부터 시계방향)으로 나눠, 플레이어 칸 + 해당 방향 1칸을 타겟으로 잡는다.
  - 타겟 칸에 포인터 이미지 표시. 블록이 있으면 파란색, 없으면 빨간색.
  - 채굴 중에도 타겟 칸은 계속 갱신된다. 마우스/플레이어 이동으로 조준 칸이 바뀌면 채굴 진행도가 리셋되고 새 칸에서 다시 시작한다.
  - 플레이 시작 시 이미 눌려 있던 클릭은 무시 (한 번 뗀 뒤부터 입력 받음).

## 벽타기

- 원 기획: 귀환할 때 수동으로 올라와야 하며, 블록이 없어도 벽을 탈 수 있다.
- 현재 구현:
  - 이동 입력 직후 0.5초 안에 Shift를 누르면 벽타기 모드 진입 → 중력 0, 벽타기 스프라이트로 변경.
  - 벽타기 중에는 **뒷배경 타일(back tilemap)이 있는 칸 = 이미 파낸 공간** 안에서만 상하좌우 이동 가능.
  - 진입 후 1초간은 해제 불가. 이후 바닥에 닿으면 자동으로 일반 모드로 복귀.
- 영구 아이템 **클로**로 벽타기 속도 증가 (→ `06_Items.md`)

## 애니메이션 상태 (🔧 코드 구현, 플레이 테스트 미완료 — 에셋 PPU 재제작 대기)

플레이어 아래에 앞모습(`Mole`)·뒷모습(`Mole_Back`) 모델을 자식으로 두고, `isClimb`에 따라 한쪽만 켠다. `PlayerManager`가 활성 모델의 Animator에 파라미터를 보낸다.
좌우 반전은 본 리깅이라 `flipX` 대신 모델 루트 `localScale.x`로 한다.

| 모드 | 컨트롤러 | 상태 | 파라미터 / 전환 조건 |
| --- | --- | --- | --- |
| 지상 | `Mole_Front` | Idle | 기본 |
| | | Walk | `IsMoving` (좌우 입력 + 바닥) |
| | | Mine (`Front_Mine_1`) | `IsMining` (Idle/Walk 어느 쪽에서든 우선) |
| 벽타기 | `Mole_Back` | Idle | `MoveX`, `MoveY` 모두 0 |
| | | Side | `MoveX` > 0 (`MoveY`가 0일 때) |
| | | Up | `MoveY` > 0 (위/아래 이동 모두 Up 재생. `MoveX`/`MoveY`는 절댓값) |

- 채굴 중 이동 가능. 조준 칸이 바뀌면 채굴 리셋.
- 벽타기 중에도 채굴 가능하나 **뒷모습 채굴 애니메이션은 없음** (뒷모습 그대로 연출 없이 채굴). 추후 제작 시 추가.
- 8방향 조준 모두 같은 Mine 애니메이션 사용 (방향별 연출은 추후).
- `Front_Mine_2`는 제작 중이라 삭제함.

## 미정

- 점프 여부 (현재 없음)
- 벽타기 속도 기본값 (현재 일반 이동속도와 동일)
- 곡괭이 시각 표현: 현재는 포인터만 있고 곡괭이 스프라이트가 마우스를 따라 움직이는 연출은 없음
- 낙하 처리: 현재 바닥이 없으면 수평 이동이 막히고 로그만 출력됨 (낙하 데미지 등 미정)
