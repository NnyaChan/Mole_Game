# 04. 랜턴 & 하루

## 랜턴 = 하루의 시간 ✅ 구현됨 (`LanternManager`, `LanternUI`)

- 랜턴 배터리 10칸, **광산 안(Depth ≥ 0)에서 10초에 1칸** 감소 → 하루 최대 100초
  - `dayDuration = 100`, `segments = 10`
- 지상(맵 밖)에서는 줄지 않는다.
- UI: 칸 이미지를 칸 수만큼 생성, 오른쪽부터 사라짐
- 0이 되면 `GameManager.EndDay(현재 Zone)` 호출

## 귀환

- 배터리가 다 떨어지기 전에 **지상(맵 상단 4칸 이내)** 으로 올라와야 한다.
- 배터리를 확인하며 수동으로 올라와야 함. 블록이 없어도 벽을 탈 수 있음 (→ `01_Player_Controls.md`)
- 지상에 올라오면 → 까마귀가 광물 회수 → 귀가 → 랜턴 충전하며 취침(자동저장)

## 배터리 소진 (조난) 패널티

1. 화면 암전 (1초)
2. **그날 모은 광물의 50% 손실**
3. 구조대가 구출 → 지상에서 눈을 뜸
4. **구출 비용 지불** 후 집에 돌아갈 수 있음 (돈이 부족하면 마이너스 계좌 가능, **한도 없음**)

## 현재 구현 상태

- ✅ 랜턴 소진 → 일차 종료 → 암전(`BlackoutFader`, 1초) → Day+1 → 씬 재로드(맵/플레이어/랜턴 초기화)
- ✅ 소진 시점의 Zone을 지상/지하로 판정해 로그 출력
- ✅ 2일차부터 검은 화면에서 페이드인으로 시작
- ✅ 일차 종료 시 자동저장 (Day+1 직후, `PlayerData` → `save.json`)
- 지상(광산 밖)에서는 랜턴이 줄지 않아 하루가 끝나지 않는다. **의도된 설계**이며 오류가 아니다.
- ❌ 귀환 성공 시 까마귀 회수·귀가/취침 연출 (연출 영역, 지상 맵과 함께 진행)
- ❌ 조난 패널티 (광물 50% 손실, 구출 비용, 마이너스 계좌)

## 미정

- 구출 비용 금액 (고정 / 깊이 비례 / 소지금 비례)
- 마이너스 계좌 이자 여부 (한도는 없음으로 확정)
- 지상(4칸 이내)에서 배터리가 소진된 경우의 처리 (현재는 "귀환 성공"으로 판정)
- 하루 종료 트리거: 집 문/침대와 상호작용? 지상에 올라오면 자동?
- 배터리 부족 경고 연출 (깜빡임, 사운드 등)

## 관련 아이템
