# 06. 아이템

> 이 문서의 내용은 전부 ❌ 미구현.

## 공통 규칙

- 기본적으로 **인터넷 상점**에서 구매 (밤에 주문 → 다음 날 아침 풍선 배송)
- 아이템마다 **최대 보유량**이 있다 (아래 표).
- 한 번 사용하면 소모되며, 남은 아이템은 다음 날에도 유지된다.
- 사용 방법: **인벤토리의 아이템을 클릭**하여 사용

## 가격 & 최대 보유량

| 아이템 | 분류 | 가격 | 최대 보유량 |
| --- | --- | --- | --- |
| 클로 +1 | 영구 | 50G | 1 |
| 클로 +2 | 영구 | 100G | 1 |
| 클로 +3 | 영구 | 150G | 1 |
| 다이너마이트 Lv1 | 소모 | 2G | 3 |
| 다이너마이트 Lv2 | 소모 | 15G | 3 |
| 다이너마이트 Lv3 | 소모 | 50G | 3 |
| 일회용 보조배터리 | 소모 | 50G | 1 |
| 에너지 음료 | 소모 | 30G | 3 |
| 커피 | 소모 | 20G | 3 |

> 시트에는 클로 +2가 두 줄(100G, 150G)로 적혀 있어 두 번째 줄을 클로 +3으로 해석함 (확인 필요)

## 영구 아이템

### 클로 — 벽타기 속도 영구 증가

| 단계 | 효과 |
| --- | --- |
| 클로 +1 | 벽타기 속도 +10% |
| 클로 +2 | 벽타기 속도 +20% |
| 클로 +3 | 벽타기 속도 +30% |

- 상위 단계는 하위 단계를 대체 (중첩 아님). **+1 → +2 → +3 순서로만 구매 가능** (확정).

## 소모 아이템

### 다이너마이트

- 플레이어를 중심으로 원형 범위의 블록을 파괴한다.
- 층이 깊을수록 파괴 반경이 줄어든다. (표의 숫자 = 상하좌우 반경 칸 수)

| 단계 | 흙(1층) | 돌(2층) | 맨틀(3층) | 외핵(4층) | 내핵(5층) |
| --- | --- | --- | --- | --- | --- |
| Lv1 | 3 (지름 7) | 2 | 1 | 사용 불가 | 사용 불가 |
| Lv2 | 5 (지름 11) | 4 | 3 | 2 | 사용 불가 |
| Lv3 | 7 (지름 15) | 6 | 5 | 4 | 3 |

- 원 기획서의 Lv2 설명에 "내핵까지 사용 가능"이라 적혀 있으나 표에는 내핵 사용 불가로 되어 있음 → **표 기준으로 정리, 확인 필요**
- "사용 불가" 층에서 사용 시: 블록이 파괴되지 않음 (아이템 소모 여부는 미정)
- 다이너마이트는 하루 채굴량을 크게 늘리는 수단 (`08_Balance.md`: 평소 하루에 층의 약 1/3 채굴 가정)

### 기타 소모품

| 아이템 | 효과 |
| --- | --- |
| 일회용 보조배터리 | 랜턴 배터리 15% 회복 (10칸 기준 1.5칸 = 15초) |
| 에너지 음료 | 20초 동안 채굴 속도 +20% |
| 커피 | 10초 동안 이동 속도 +20% |

## 미정

- 다이너마이트 파괴 시 광물이 드랍되는지, 곡괭이 단계로 캘 수 없는 광물도 부서지는지
- 다이너마이트에 플레이어 피해가 있는지
- 버프 중복 사용 시 시간 연장 / 효과 중첩 여부
