# 09. 세이브 테스트용 플레이어 데이터 (임시안)

> **목적**: 세이브/불러오기 기능이 동작하는지 개발 중에 시험하기 위한 데이터 목록.
> 기획이 확정된 것이 아니라 **테스트용 임시안**이다. 아래 표를 고치면 그대로 코드로 옮긴다.
> 표의 **"기획 근거"** 칸이 비어 있거나 "미정"이면 기획 확정 전의 임시 항목이다.

## 읽는 법

- **저장 항목**: 게임을 껐다 켜도 남아야 하는 값
- **테스트 시작값**: 새 게임을 시작했을 때의 값. 기획 확정 전에는 테스트용으로 임의로 둔 것이다.
- **타입**: 정수 / 참거짓 / 글자 / 목록 / 사전(이름 → 값)

## 1. 기본 진행

| 저장 항목 | 설명 | 타입 | 테스트 시작값 | 기획 근거 |
| --- | --- | --- | --- | --- |
| 저장 버전 | 나중에 저장 구조가 바뀔 때 구분용 | 정수 | 1 | (개발용) |
| 일차 | 현재 며칠째인지 | 정수 | 1 | `00_Overview.md` (약 15일) |
| 소지금 | 가진 돈(G). **마이너스 가능** | 정수 | 0 | `05_Economy.md`, `04_Lantern_Day.md` (마이너스 계좌) |

> 시작 소지금은 기획 미정이다. 테스트에서는 0으로 둔다.

## 2. 장비

| 저장 항목 | 설명 | 타입 | 테스트 시작값 | 기획 근거 |
| --- | --- | --- | --- | --- |
| 곡괭이 단계 | Lv1~Lv6 | 정수 | 1 | `03_Blocks_Mining.md` |
| 클로 단계 | 0 = 없음, 1~3 = 클로 +1~+3. 상위가 하위를 대체(중첩 아님) | 정수 | 0 | `06_Items.md` |

## 3. 소모 아이템 보유량

이름(ID)별로 개수를 저장한다. 최대 보유량을 넘길 수 없다.

| 아이템 이름(ID) | 표시 이름 | 최대 보유량 | 테스트 시작값 |
| --- | --- | --- | --- |
| dynamite_1 | 다이너마이트 Lv1 | 3 | 0 |
| dynamite_2 | 다이너마이트 Lv2 | 3 | 0 |
| dynamite_3 | 다이너마이트 Lv3 | 3 | 0 |
| battery | 일회용 보조배터리 | 1 | 0 |
| energy_drink | 에너지 음료 | 3 | 0 |
| coffee | 커피 | 3 | 0 |

- 개수 0인 아이템은 저장하지 않아도 된다. (없으면 0개로 본다)
- 아이템 이름(ID)은 한 번 정하면 바꾸지 않는다. 표시 이름은 자유롭게 바꿔도 된다.

## 4. 배송 대기 주문

밤에 주문하면 **다음 날 아침 풍선으로 도착**한다. 도착 전까지 저장해야 하는 목록이다.

| 저장 항목 | 설명 | 타입 | 테스트 시작값 |
| --- | --- | --- | --- |
| 배송 대기 목록 | 주문한 물품 목록. 한 줄에 `아이템 이름(ID)`와 `개수` | 목록 | 비어 있음 |

- 곡괭이 강화와 클로도 주문으로 들어오므로, 이름(ID)은 `pickaxe_2` ~ `pickaxe_6`, `claw_1` ~ `claw_3` 처럼 정한다.
- 주문 시점의 가격까지 저장할지는 미정이다. (테스트에서는 저장하지 않는다)

## 5. 이번 테스트에서 일부러 뺀 것

기획이 정해지지 않았거나, 저장하지 않아도 되는 값이다.

| 항목 | 이유 |
| --- | --- |
| 오늘 획득한 광물 목록 | 로드맵 3번에서 다룸. 취침 시 정산되면 비워지므로 하루 중간 저장 여부가 미정 |
| 광물 시세 변동 | 뉴스 기획(변동 폭 등) 미정 |
| 광산 맵 | 하루가 시작될 때 다시 랜덤 생성하므로 저장 불필요 (저장 시점이 취침 시) |
| 랜턴 남은 시간 | 집에서 충전하며 자므로 아침에는 항상 가득 참 |
| 누적 통계, 도감, 업적 | 도전 영역(로드맵 13~15번) |
| 버프 남은 시간(에너지 음료, 커피) | 하루 안에서만 유지되는지 미정 |

## 6. 저장 시점 (테스트 기준)

- **취침 시 자동저장**: `정산 → 상점 → 잠자기` 중 "잠자기" 단계에서 저장한다. (`05_Economy.md`)
- 테스트용 보조 수단으로 키 입력으로 저장/불러오기/초기화를 따로 둘 수 있다. (기획 확정 사항 아님)

## 7. 기획 확인이 필요한 것

- 시작 소지금은 얼마인가
- 시작할 때 가지고 있는 아이템이 있는가 (없다면 모두 0)
- 클로를 순서대로만 살 수 있는가 (`06_Items.md` 미정)
- 하루 중간에 게임을 종료하면 그날 진행을 어떻게 처리하는가 (취침 시에만 저장하면 그날 진행은 사라진다)
