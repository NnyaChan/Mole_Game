### 순서 목록에 없는 것 (필요 시점에 끼워 넣기)

- 지상 맵 (집, 침대, 까마귀) 및 연출: 지상 귀환 → 까마귀 회수 → 귀가/취침 흐름. 하루 종료 트리거(자동 vs 침대 상호작용)가 정해지면 진행
- 핸드폰 정산 화면 UI 배치: 현재는 기능 확인용 임시 화면(`SettlementUI`). 핸드폰 모양과 아트 스타일, 레이아웃을 정해 배치해야 한다. 폰트는 한글 폰트 제작 후 적용 (→ `07_UI.md`)
- 세이브 호출 위치를 일차 종료 시점에서 취침 시점으로 이동 (취침 흐름이 생길 때)
- 세이브 테스트 키(F5/F9/F12)를 설정키로 대체
- 특수 광물 → 도감(14번)과 함께 기획 확정 필요

## ❓ 결정이 필요한 항목

구현 전 사용자에게 확인할 것.

- 시세 변동 폭, 하루에 변동되는 광물 수
- 구출 비용, 마이너스 계좌 한도
- 하루 종료 트리거 (지상 도착 자동 vs 침대 상호작용)
- Lv3 곡괭이의 흑요석 채굴 가능 여부 (시트 빈칸, 코드 0.9초)
- 다이너마이트 Lv2의 내핵 사용 가능 여부
- 시트의 "클로 +2" 두 번째 줄 = 클로 +3이 맞는지 (세이브/구매 순서는 +1 → +2 → +3으로 이미 확정)
- Lv3~Lv5 곡괭이 이름
- 특수 광물, 도전과제 내용
- 15일 이후 목표 / 엔딩

## 🧹 정리 필요 (사용자가 Unity 에디터에서 직접)

- `TileBreaker.ClickBlock`은 빈 함수 (씬의 PlayerInput 이벤트 연결 해제 후 삭제 가능)

## 🛠 수정 필요 (보류 중)

- **Break(균열) 애니메이션이 플레이어의 곡괭이보다 위에 그려짐**: 곡괭이가 균열에 가려 보인다. 애니메이션 전체의 정렬 레이어(Sorting Layer / Order in Layer) 조정이 필요해서, 당장은 수정을 미루고 보류한다. 캐릭터 애니메이션(순서 1번) 마무리 시점에 레이어 전반을 함께 정리할 것.
