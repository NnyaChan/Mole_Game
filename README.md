# Mole_Game

B급 병맛 감성의 2D 채굴 게임입니다. 매일 새로 생성되는 5층 광산을 파 내려가 광물을 캐고,
랜턴(= 하루의 시간)이 꺼지기 전에 지상으로 돌아와 광물을 팔고 장비를 사는 것이 핵심 루프입니다.

> 현재 개발 중입니다. 이 문서의 **게임 소개**는 완성본 기준이고, 실제 구현 정도는 [진행도](#진행도)에서 확인할 수 있습니다.

## 게임 소개

- **확실한 노가다** 채굴 게임. 이상한 광물을 이상한 그림체로 정말 이상하게 캐 나갑니다.
- 플랫폼: PC (키보드 + 마우스)
- 목표 플레이 타임: 약 15일(게임 속 일차) 동안 곡괭이 Lv1 → Lv6, 1층 → 5층까지 진행

### 하루의 흐름

```
기상 → 광산 진입 → 채굴 (랜턴 소모) → 지상 귀환 → 까마귀가 광물 회수
  ↑                                                    ↓
뉴스(시세 확인) ← 인터넷 쇼핑 ← 핸드폰 정산 ← 귀가 & 취침(자동저장)
```

1. **기상**: 전날 밤 인터넷 쇼핑으로 주문한 물품이 풍선을 타고 도착해 있습니다.
2. **채굴**: 광산에 들어가면 랜턴 배터리가 줄기 시작합니다. (10칸, 10초에 1칸)
3. **귀환**: 배터리가 다 떨어지기 전에 지상으로 올라와야 합니다. 실패하면 암전 → 그날 모은 광물 50% 손실 → 구조대 구출 → 구출 비용 지불.
4. **판매**: 광산에서 나오면 까마귀가 광물을 가져갑니다.
5. **정산·쇼핑**: 취침할 때 핸드폰으로 판매 금액을 정산하고, 곡괭이와 아이템을 주문합니다.
6. **뉴스·기상**: 다음 날 광물 시세 변동을 확인하고 하루가 시작됩니다. 이때 자동저장됩니다.

### 광산

- 총 5층, 한 층은 가로 15 × 세로 10 블록입니다. 광물 배치는 **매일 랜덤**으로 바뀝니다.
- 위에서부터 흙 → 지각(돌) → 맨틀 → 외핵 → 내핵 순서이고, 깊을수록 비싼 광물이 나옵니다.
- 곡괭이 단계에 따라 파고 내려갈 수 있는 층이 제한됩니다.

| 층 | 이름 | 등장 광물 |
| --- | --- | --- |
| 1 | 흙 | 돌, 구리, 납 |
| 2 | 지각(돌) | 돌, 구리, 납, 철, 금 |
| 3 | 맨틀 | 구리, 납, 철, 금, 흑요석, 사파이어 |
| 4 | 외핵 | 철, 금, 흑요석, 사파이어, 에메랄드 |
| 5 | 내핵 | 금, 흑요석, 사파이어, 에메랄드, 루비, 다이아몬드 |

### 조작

| 입력 | 동작 |
| --- | --- |
| A / D | 좌우 이동 |
| 마우스 이동 | 곡괭이 방향 조준 (8방향) |
| 마우스 좌클릭 (누르고 있기) | 채굴 |
| Shift (이동 직후) | 벽타기 모드. 파낸 공간 안에서 W / S / A / D로 이동 |
| 인벤토리 아이템 클릭 | 아이템 사용 |
| F5 | 저장 (개발용 임시 키) |
| F9 | 불러오기 — 마지막 저장 시점의 일차 처음부터 다시 시작 (개발용 임시 키) |
| F12 | 초기화 — 세이브 삭제 후 새 게임 (개발용 임시 키) |

### 성장 요소

- **곡괭이** Lv1 ~ Lv6: 상점에서 구매. 단계가 오를수록 더 깊은 층과 단단한 광물을 캘 수 있고 채굴 시간이 줄어듭니다.
- **클로**(영구 아이템) +1 ~ +3: 벽타기 속도 증가
- **소모 아이템**: 다이너마이트(범위 파괴), 일회용 보조배터리(랜턴 회복), 에너지 음료(채굴 속도), 커피(이동 속도)
- **뉴스**: 매일 특정 광물의 시세가 하루 동안 변동됩니다.

## 진행도

범례: ✅ 구현 완료 / 🔧 진행 중 / ❌ 미구현

### 구현 완료

- ✅ 5층 랜덤 맵 생성 (Tilemap 기반, 층별 광물 개수 범위 지정)
- ✅ 플레이어 좌우 이동, 벽타기
- ✅ 마우스 8방향 조준과 포인터 표시
- ✅ 누르고 있기 채굴, 곡괭이 단계별 채굴 시간표, 채굴 균열 애니메이션
- ✅ 깊이/구역 판정 (광산 진입, 귀환 구역)
- ✅ 랜턴(광산 안에서만 소모)과 UI, 깊이 게이지 UI
- ✅ 랜턴 소진 → 암전 → 다음 날(씬 재로드)

### 진행 중

- 🔧 **캐릭터 애니메이션**: 대기/이동/벽타기/채굴 상태 전환 코드는 작성했지만, 애니메이션 에셋의 크기(PPU) 문제로 재제작을 기다리는 중이라 **아직 플레이 테스트를 하지 못했습니다.**

### 아직 정해지지 않은 기획

시세 변동 폭, 구출 비용과 마이너스 계좌 한도, 하루 종료 트리거(자동 / 침대 상호작용), 특수 광물, 도전과제, 15일 이후 목표와 엔딩 등은 기획이 확정되지 않았습니다. 자세한 목록은 [Docs/Roadmap.md](Docs/Roadmap.md)에 있습니다.

## 개발 환경

- 엔진: Unity 6000.5.9f1 (URP 2D)
- 입력: New Input System (`Assets/Settings/InputSystem_Actions.inputactions`)
- 씬: `Assets/0. Scenes/SampleScene.unity` 하나. 하루가 끝나면 이 씬을 다시 로드합니다.

### 실행 방법

1. Unity Hub에서 이 폴더를 프로젝트로 추가하고 위 버전의 에디터로 엽니다.
2. `Assets/0. Scenes/SampleScene.unity`를 열고 Play를 누릅니다.

### 폴더 구조

| 폴더 | 내용 |
| --- | --- |
| `Assets/0. Scenes` | 씬 |
| `Assets/1. Scripts` | 스크립트 (Map, Mining, Lantern, UI, ScriptableObject, 매니저류) |
| `Assets/2. Sprites` | 스프라이트 |
| `Assets/3. Prefabs` | 프리팹과 데이터 에셋(ScriptableObject) |
| `Assets/4. Materials` | 타일 에셋 |
| `Assets/7. Animations` | 애니메이션 클립, 컨트롤러 |
| `Docs` | 기획 문서 |

### 코드 구조 요약

- `GameManager`: 상태(Playing/Ending), 일차, 하루 종료 → 암전 → 씬 재로드
- `RandomMapGenerator`: 층 데이터(`Floor`)를 읽어 Tilemap에 맵 생성
- `TileBreaker`(조준) → `MiningController`(채굴 시간 계산, 파괴) → `BlockBreakEffect`(균열 연출)
- `BlockCatalog`: 타일 → 블록 종류 매핑과 곡괭이 단계별 채굴 시간표
- `LanternManager` / `LanternUI`: 광산 안에서만 시간 감소, 0이 되면 하루 종료
- `ZoneDetector`: 플레이어 깊이와 귀환 가능 구역 판정
- `PlayerManager`: 이동, 벽타기, 캐릭터 애니메이션 연결

시스템 간 연결은 `event Action`과 `FindAnyObjectByType`으로 느슨하게 이어져 있습니다.
